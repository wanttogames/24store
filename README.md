# 심야 편의점: 03:17

Phaser 3 + TypeScript + Vite로 만든 PC·모바일 브라우저용 관찰 추리 괴담 게임의 플레이 가능한 MVP입니다. 캐릭터를 이동시키지 않고, 손님·상품·CCTV·시간을 비교해 계산 / 거절 / 신고 / 무시를 결정합니다.

## 실행

Node.js 22.12 이상 권장.

```bash
npm ci
npm run dev
```

```bash
npm test
npm run build
npm run preview
```

브라우저 검증은 `npx playwright install chromium` 후 `npm run test:browser`로 실행합니다. 7일 전체 진행, 새로고침 재개, 엔딩 화면, 모바일 터치와 가로 넘침을 확인합니다. 설치된 Chromium을 쓰려면 `CHROMIUM_EXECUTABLE_PATH`를 지정할 수 있습니다.

`dist/`를 정적 호스팅에 올리면 됩니다. 상대 asset 경로를 사용하므로 GitHub Pages `/24store/`와 Cloudflare Pages 모두 대응합니다. 외부 API·서버·DB·외부 폰트 없이 실행합니다.

## 구현 범위

- 7일 근무, 하루 12명. 보통 8~11명은 일반 손님이며, 외모가 수상해도 정상인 손님 포함.
- 일반 손님 8종, 상품 15종, 이상 사건 10종 + 03:17 스토리.
- 매일 03:17 고정 손님. 점장 메모, 과거 기사, 상품 라벨, 저장 영상을 통한 스토리 단서.
- 계산 / 거절 / 신고 / 무시 및 사건별 잠금 / 소등 / 숨기 / 뒤돌아보기 / 마지막 계산.
- 정신력, 점장 신뢰, 매출. 낮은 정신력에서는 실시간 CCTV 해석이 불안정해지고 상품명 환각이 발생. 저장 영상으로 비교 가능.
- 얼굴 없는 손님 결제 시 추가 이상 사건 압력 증가.
- NORMAL / BAD / FIRED / MISSING / TRUE, 5개 엔딩.
- 일별 근무 일지, 정확히 해결한 사건만 열리는 괴담 도감, 엔딩 수집.
- LocalStorage 자동 저장 및 응대 중 재개. 새 근무는 도감·엔딩 수집을 유지.
- Phaser 코드로 그린 2D 편의점·손님·상품, 역할별 소지품·복장, 눈 깜빡임·호흡·고개 움직임, 비·유리 반사·생활 소품·입장 페이드, Web Audio 환경음·벨·스캔음.
- 계산대 모니터와 확대 화면은 동일한 실제 CCTV 피드를 표시. 얼굴 없음·빈 계산대 속 손님·과거 명찰/날짜·검은 그림자·상품 날짜 불일치를 시각적으로 표현.
- 마우스·터치 대응 UI. 메뉴·관찰 모달·백그라운드 상태에서 시간 정지.

## 시간 / 난이도

한 응대 구간은 18초 동안 게임 시계가 흘러갑니다. 응대가 길어지면 다음 사건 직전에 시간이 대기하므로 03:17 스토리를 건너뛰지 않습니다. 판단 후 **다음 응대** 버튼으로 진행합니다. 7일은 일반적인 관찰 속도 기준 20~30분을 목표로 하며, 빠르게 넘기면 더 짧게 끝납니다. 실제 사용자 플레이 타임은 아직 측정하지 않았습니다.

마지막 손님만 폐점 이후 06:01에 등장합니다. 정신력 0 / 신뢰 0은 즉시 종료됩니다. 일반 손님을 반복 거절하면 해고됩니다.

## 구조 / 콘텐츠 추가

- `src/data/` — 손님, 상품, 이상 사건, 스토리, 엔딩
- `src/systems/` — 일정 생성, 판단 및 단서 수집, 시계, 정신력, CCTV, 저장, 사운드
- `src/scenes/` — Boot / Menu / Game / DayResult / Ending 및 고정 편의점 렌더러
- `src/ui/App.ts` — 반응형 HTML UI, 모달, 입력 연결
- `tests/engine.test.ts` — 캠페인, 다섯 엔딩, 단서, 중복 보상, 저장 및 시간 경계 검증

이상 사건은 `src/data/anomalies.ts`에 추가합니다. `correct`로 적절한 행동, `extra`로 추가 버튼, `fatal`로 실종 행동, `productClue`와 `cctv`로 비교 단서를 설정합니다. 일반 사건은 GameScene에 조건을 추가할 필요가 없습니다. 고정 이야기 이벤트는 `story.ts`, 등장 일정을 바꾸려면 `CustomerManager.ts`를 수정합니다.

## 제작 단계와 한계

이 버전은 전체 게임 루프를 검증하는 프로토타입입니다. 캐릭터는 코드로 그린 도형 일러스트이며, 역할별 외형과 미세한 움직임을 제공합니다. CCTV는 실제 렌더링한 매장·손님·상품을 보여주고 설명 단서를 함께 제공합니다. 최종 캐릭터 원화, CCTV 다중 카메라, 손동작·퇴장 연출, 추가 대사·현장 사운드는 후속 작업 대상입니다. 외부 음원과 이미지 라이선스 의존성이 없습니다.

## GitHub Pages

`.github/workflows/pages.yml`은 `main`에 반영될 때 자동 배포하며 수동 실행도 지원합니다. 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택하세요. 최초 설정 후 Actions → Deploy game to Pages → Run workflow를 실행하면 됩니다. 이후 변경은 테스트와 빌드 후 자동 배포됩니다. 실행 주소: https://wanttogames.github.io/24store/
